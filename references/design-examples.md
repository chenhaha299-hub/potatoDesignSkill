# 设计输出示例

## 示例 1：宠物咖啡店预约小程序

**设计目标**：让 40 岁老板娘和首次到店顾客 30 秒完成预约。

**主路径**：
```
打开小程序 → 首页（店介绍+立即预约按钮）→ 选日期时段 → 填信息 → 提交成功（含到店指引）
```

**页面清单**：

```markdown
### 页面：首页
- 职责：说明店铺 + 引导预约
- 元素顺序：店铺名+一句话介绍 → 营业时间 → 【立即预约】主按钮（底部大按钮）
- 状态：加载中=骨架屏；错误=网络重试

### 页面：选日期时段
- 职责：完成时间选择
- 元素顺序：日期横滑选择（默认今天）→ 时段列表（已满置灰）
- 关键规则：已满时段显示"已约满"并置灰；选择后底部固定【下一步】按钮
- 状态：空状态=今日已约满，提示选明天

### 页面：填写信息
- 职责：收集联系方式
- 元素顺序：宠物数量(步进器) → 手机号(数字键盘) → 备注(可选) → 【提交预约】
- 关键规则：手机号即时校验；提交中按钮转圈防重复提交
- 状态：成功=跳转成功页；失败=顶部红色提示保留已填内容
```

**视觉规范**：
- 主色：#8B5E3C（木质暖棕，呼应宠物咖啡店），强调色：#E8A87C（奶油橘），背景：#FAF6F1（米白）
- 圆角 16px，卡片留白 16px
- 字体：系统字体栈

**摩擦检查**：
| 位置 | 问题 | 修复 |
|---|---|---|
| 选时段 | 满座时段提交才报错 | 已满置灰+角标"已满" |
| 首页 | 新客不知道能干嘛 | 顶部一句话+大按钮 |
| 提交 | 无防重复 | 按钮提交中转圈禁用 |

## 示例 2：个人记账网页工具

**设计目标**：下班后 10 秒记完一笔账，月末 1 分钟看懂钱花哪了。

**主路径**：打开 → 首页（本月总支出+最近记录）→ 记一笔 → 成功（留在首页自动刷新）

**关键页面**：

```markdown
### 页面：首页（记账工具的核心）
- 职责：本月概览 + 快速记账入口
- 元素顺序：本月支出大字 → 分类占比简图 → 【记一笔】悬浮主按钮 → 最近 10 条记录
- 关键规则：悬浮按钮始终可见；数字用等宽字体对齐
```

**摩擦检查**：
| 位置 | 问题 | 修复 |
|---|---|---|
| 记一笔 | 分类选择太多（20 类） | 只显示最近常用的 5 类 + "更多" |
| 报表 | 折线图看不懂 | 默认"分类占比"条形图 + 白话结论（"餐饮占比最高 45%"）|

## 示例 3：AI 工具内容社区（小红书引流落地页）

**设计目标**：让刷到笔记的人 10 秒理解价值并愿意关注/进私域。

**页面**：落地页单页 = 标题（利益点）→ 3 个价值点（图标+一句话）→ 案例截图 → 关注/领取按钮 → 常见问题

**关键规则**：
- 首屏 = 标题 + 主按钮，不滚动就能看到；
- 按钮文案具体化："领取 30 个 AI 工具清单" 优于 "了解更多"；
- 移动端单手可点，留白足够。
